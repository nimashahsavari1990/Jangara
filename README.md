# آرشیو متنی و کتابخانه آثار نیما شهسواری

نظریه‌پرداز، شاعر و نویسنده ایرانی | **پایگاه مرجع:** [جهان آرمانی](https://idealistic-world.com)

این مجموعه شامل آرشیو متنی، پژوهش‌های ساختاری، کتب فلسفی و متون ادبی نیما شهسواری بر پایه مفاهیم **پارادایم جان‌گرایی**، نقد ساختارهای قدرت، حقوق حیوانات و برابری انسان و تمام جانداران است که به‌صورت آزاد جهت مطالعه و پژوهش عمومی منتشر گردیده است.
